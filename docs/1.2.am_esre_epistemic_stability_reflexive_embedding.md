## 1.2.am.1 Purpose

1.2.af established Lyapunov stability under bounded revision in E = (M,L,X,C,H).
1.2.ak–1.2.al introduced RVE and proved epistemic closure, extending to
E* = (M,L,X,C,H,V).

> Central claim: The reflexive loop (RVE) does not destroy Lyapunov stability,
> provided the embedding is history-only (default) or bounded-coupled with
> explicit small-gain constraints.

---

## 1.2.am.2 Two Embedding Modes

### Mode A — History-Only Embedding (HOE)

RVE updates only H and V axes:

```
δ*(E*, e_vts) = (M, L, X, C, H', V')
with (M, L, X, C) unchanged
```

This is the default normative mode.

### Mode B — Bounded-Coupled Embedding (BCE)

RVE may influence governance, which may indirectly affect Z = (M,L,X,C):

```
||ΔZ_t|| ≤ α · ||ΔV_t||
```

where α must satisfy stability constraints (see 1.2.am.6).

---

## 1.2.am.3 Theorem ESRE-1 (HOE Stability Preservation)

If 1.2.af Lyapunov stability holds for E, and RVE updates only H/V without
changing (M,L,X,C), then base manifold stability is preserved.

**Proof:** In Mode A, base axes are unchanged at each step. Any Lyapunov
function V(E) retains its monotone decrease properties because its argument
is unchanged. Basin membership (1.2.ah) remains consistent.

---

## 1.2.am.4 Theorem ESRE-2 (Extended Stability on E*)

Define extended Lyapunov function:

```
W*(E*) = W(E) + λ_V · W_V(V)
```

If W(E) is stable per 1.2.af, and W_V growth is bounded per step:

```
W_V(V_{t+1}) - W_V(V_t) ≤ B_V
```

then W* is Lyapunov-stable in the bounded-input sense.

---

## 1.2.am.5 Theorem ESRE-3 (Small-Gain Stability in Mode B)

With coupling gain α and base stability margin β:

```
Small-gain condition: α · λ_V < β
```

If satisfied, reflexive coupling cannot override base stability.
