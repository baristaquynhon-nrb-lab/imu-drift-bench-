## 1.2.aj.2 Observable Drift Vectors

At each CLP step t:

```
E_t = (M_t, L_t, X_t, C_t, H_t)
```

Measurable drifts:

```
ΔM_t = d_M(M_t, M_{t-1})
ΔL_t = d_L(L_t, L_{t-1})
ΔX_t = d_X(X_t, X_{t-1})
ΔC_t = d_C(C_t, C_{t-1})
```

Only CG-admissible steps are used for K_ML and K_LT:

```
Ω = { t : CG_OK(t) = true }
```

## 1.2.aj.3 Coupling Definitions

### K_ML (Meaning → Law)

```
K_ML = median(|ΔL_t|, t ∈ Ω) / median(|ΔM_t|, t ∈ Ω)
```

### K_LT (Law → Topology)

```
K_LT = median(|ΔX_t|, t ∈ Ω) / median(|ΔL_t|, t ∈ Ω)
```

### K_C (Coherence dampening)

```
K_C = median(|ΔL_t|, t ∈ Ω) / median(|ΔL_t|, t ∉ Ω)
```

Interpretation: K_C < 1 means coherence constrains (dampens) drift.
K_C > 1 would indicate coherence amplifies drift (pathological).

---

## 1.2.aj.4 Robust Estimation Rules

### R1 — Median-based (no mean)

All ratios use median, not mean, for outlier robustness.

### R2 — Outlier removal via Q99

For each drift axis, before computing median:
- Sort values ascending
- Compute Q99 = sorted[floor(0.99 * (n-1))]
- Remove values strictly > Q99
- Proceed with filtered set

### R3 — Minimum sample size

After Q99 filtering, require n ≥ 5 per axis per group.
If not met → REFUSE for that coupling constant.

### R4 — Zero denominator

If median of denominator axis = 0:
- K is undefined (null)
- Not a REFUSE; other K values still computed

### R5 — IEEE-754 safety

All drift values must be finite. Non-finite → REFUSE.

---

## 1.2.aj.5 Determinism Requirements

CCEP MUST:
- Use canonical sort order
- Use no random seed or stochastic process
- Produce identical output on identical input (replay-verifiable)
- Fail-fast on non-finite drift or insufficient samples
