## 1.2.ai.1 Purpose

Sections 1.2.ae–1.2.ah define ESM and its phase-space partition:

- Basin interior B(E*, ε_L, m)
- Boundary shell S(E*, ε_L, m)
- Mutation region M(ε_L, m)

However, ε_L and m are currently **configuration parameters**.

This section defines **BREP**: a deterministic, replay-verifiable protocol that
**estimates**:
- **ε_L** (basin radius w.r.t. law drift)
- **m** (boundary shell half-width)

from a CLP-replayable session trace (or from controlled synthetic vectors),
without introducing randomness, hidden heuristics, or non-reproducible fit.

> Central claim: ε_L and m can be operationally estimated from drift statistics
> on CG-admissible segments, producing stable phase boundaries.

---

## 1.2.ai.2 Inputs and Preconditions

### Inputs

BREP operates on an event-indexed sequence (CLP steps):

```
E_t = (M_t, L_t, X_t, C_t, H_t)
```

Required measurable features per step:
- `law_drift_algebra(t)` (ΔL in 1.2.ag / 1.2.ah)
- `cg_ok(t)` (CG admissibility)

Optional:
- `topology_region(t)` or LDBC classifier output (for cross-check only)

### Preconditions

- The session is replay-verifiable: hash-chain is intact.
- `cg_ok(t)` is deterministically recomputable from canonical inputs.
- Drift values are numeric and finite (IEEE-754 safe checks apply).

If preconditions fail, BREP MUST return REFUSE.

---

## 1.2.ai.3 Definitions

Let:
- Ω = { t : cg_ok(t) = true } (CG-admissible indices)
- D = { law_drift_algebra(t) : t ∈ Ω } (admissible drift multiset)

Define robust location/scale on D:
- median(D)
- MAD(D) = median(|d - median(D)|)

Define deterministic quantile estimator Q_p(D) using:
- sort ascending
- index = floor(p * (n-1))
- Q_p = D_sorted[index]

---

## 1.2.ai.4 Estimation Rules

BREP outputs:

- ε_L_hat (estimated basin radius)
- m_hat (estimated transition half-width)
- report (deterministic summary + integrity checks)

### Rule R1 — ε_L estimation (quantile boundary)

Select a fixed p in (0,1), default:

```
p = 0.95
```

Then:

```
ε_L_hat = Q_p(D)
```

Interpretation:
- The basin boundary is placed so that 95% of CG-admissible drifts lie inside.

### Rule R2 — m estimation (robust shell width)

Define robust spread:

```
sigma_hat = 1.4826 * MAD(D)
```

Then choose:

```
m_hat = max(m_min, k * sigma_hat)
```

Defaults:
- m_min = 0.02
- k = 1.0

Rationale:
- m_hat scales with observed drift variability in admissible regime.
- m_min prevents degenerate zero-width shells on tiny samples.

### Rule R3 — Safety clamps (optional but deterministic)

To prevent pathological boundaries:

```
ε_L_hat MUST satisfy:
  ε_L_hat ≥ ε_min  (default ε_min = 1e-6)
  ε_L_hat ≤ ε_max  (default ε_max = 1e6)

m_hat MUST satisfy:
  0 < m_hat < ε_L_hat  (if violated -> clamp or REFUSE per policy)
```

Default policy:
- clamp if mild numeric edge; REFUSE if ε_L_hat non-finite or n<3.

---

## 1.2.ai.5 Derived Phase Partition (operational)

Given ε_L_hat and m_hat, define:

```
B_hat = { t : cg_ok(t) ∧ law_drift_algebra(t) < (ε_L_hat - m_hat) }
S_hat = { t : cg_ok(t) ∧ |law_drift_algebra(t) - ε_L_hat| ≤ m_hat }
M_hat = { t : ¬cg_ok(t) ∨ law_drift_algebra(t) > (ε_L_hat + m_hat) }
```

Completeness must hold:

```
Every t is assigned exactly one of {Stable, Transition, Mutation}
(Stable ≡ B_hat, Transition ≡ S_hat, Mutation ≡ M_hat).
```

---

## 1.2.ai.6 Determinism and Replay Requirements

BREP MUST be:
- deterministic (same inputs -> same ε_L_hat, m_hat)
- replay-verifiable (computed from canonical trace artifacts)
- randomness-free (no sampling, no stochastic fit)
- fail-fast (REFUSE if insufficient data or non-finite values)
