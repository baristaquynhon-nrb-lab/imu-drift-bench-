## 1.2.ao.1 State Space & Decomposition

Extended epistemic manifold:

```
E* = (M, L, X, C, H, V)
```

Geometric decomposition:
- Base manifold: Z := (M, L, X, C) ∈ 𝒵
- Reflexive manifold: R := (H, V) ∈ ℛ
- Combined: E* ∈ ℰ* = 𝒵 × ℛ

Reflexive flow (one CLP + embedding step):

```
𝓕 : ℰ* → ℰ*,    E*_{t+1} = 𝓕(E*_t)
```

Generated by Ω (observation) + ℰ (encoding) + δ* (transition).

## 1.2.ao.2 Canonical Reflexive Vector Field

Discrete-time dynamical system. Difference "vector field":

```
ΔE*_t := E*_{t+1} − E*_t
```

Decomposition: ΔZ_t and ΔR_t.

**Mode A (HOE):**
```
ΔZ_t = 0,    ΔR_t ≠ 0 (append-only)
```

**Mode B (BCE):**
```
‖ΔZ_t‖ ≤ α‖ΔV_t‖,    αλ_V < β
```

This defines a "coupled vector field" between 𝒵 and ℛ.

## 1.2.ao.3 Global Partition of Phase Space

### (A) Basin of Reflexive Convergence

```
ℬ∞ ⊂ ℰ*
E*_0 ∈ ℬ∞ ⟹ lim_{t→∞} E*_t = E*∞
```

### (B) Stable Tube (Invariant Reflexive Tube)

```
𝒯_ε = { E* : W(Z) ≤ ε, W_V(V) ≤ B }
```

Approximately invariant region: once entered, hard to exit if ESRE
constraints hold.

### (C) Refusal Region

```
ℛ_refuse
```

Conditions: insufficient data (REFUSE), small-gain violated (BCE),
chain tamper, non-determinism. This is an absorbing stop — the system
halts with verdict REFUSE rather than continuing.

### (D) Divergence-Prevented Region

```
𝒟 ⊂ ℰ*,    entry ⟹ REFUSE
```

CAS converts divergence into epistemic refusal via gate mechanisms.

## 1.2.ao.4 Lyapunov Surfaces & Reflexive Level Sets

Base Lyapunov (1.2.af): W(Z)

Extended Lyapunov (1.2.am):
```
W*(E*) = W(Z) + γ · W_V(V)
```

Level sets:
```
Σ_c := { E* : W*(E*) = c }
```

Trajectories "descend" from higher to lower level sets:
```
W*(E*_{t+1}) ≤ W*(E*_t)
```

- HOE: W(Z) constant; W_V bounded growth with small γ.
- BCE: W(Z) decreases per small-gain; γ chosen so net W* non-increasing.

E*∞ lies at the minimum (attractor) of W* within the basin.

### (1) Attractor Characterization

```
𝓕(E*∞) = E*∞
```

E*∞ is an attractor in ℬ∞.

### (2) Local Linearization (conceptual)

```
J = D𝓕(E*∞)
```

Local stability condition:
```
ρ(J) < 1
```

Achieved in CAS via: determinism (no stochastic noise), bounded

## 1.2.ao.6 Global Convergence Scenarios

### Scenario 1 — HOE: Vertical Convergence in Fiber Bundle

View 𝒵 as base, ℛ as fiber. E* = 𝒵 × ℛ is a fiber bundle.

HOE trajectory: Z fixed, R grows along fiber. Converges to equilibrium
on base while accumulating witness chain to reflexive stability.

### Scenario 2 — BCE: Spiral Descent to Attractor

BCE creates small feedback onto Z. Portrait resembles:
- Trajectory moves on both base and reflexive fiber
- Small-gain forces contraction toward W* minimum
- Geometry: contractive spiral descent to E*∞

### Scenario 3 — Gate-induced Termination (REFUSE attractor)

Trajectories approaching unstable regions hit guard boundary.
System does not diverge — transitions to REFUSE absorbing stop.
