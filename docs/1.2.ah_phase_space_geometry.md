## 1.2.ah.2 Phase Space Decomposition

Let E* be a locally coherent reference state. Define:

### Basin (Stable region)

```
B(E*, ε_L, m) = { E ∈ E : d_L(L, L*) < (ε_L − m)  ∧  CG_OK(E) }
```

Interior of the stability region. Trajectory remains Lyapunov-stable (per 1.2.af).

### Boundary Shell (Transition region)

```
S(E*, ε_L, m) = { E ∈ E : |d_L(L, L*) − ε_L| ≤ m  ∧  CG_OK(E) }
```

Annular shell of width 2m around the basin boundary. Trajectory is admissible
but approaching phase boundary. Governance operates in PATCH mode.

### Mutation Region

```
M(ε_L, m) = { E ∈ E : d_L(L, L*) > (ε_L + m)  ∨  ¬CG_OK(E) }
```

Exterior of basin + boundary shell, OR any state where coherence is inadmissible.
Governance must invoke phase-control actions.

### Completeness

```
E = B ∪ S ∪ M    (disjoint partition)
```

Every epistemic state belongs to exactly one region.

## 1.2.ah.3 Admissible Set (CG-defined)

Define the CG-admissible set:

```
Ω = { E ∈ E : CG_OK(E) = true }
```

Properties:
- Ω is a **proper subset** of E (not all states are coherent)
- B ⊂ Ω and S ⊂ Ω by definition
- M ∩ Ω ≠ ∅ is possible (high drift but CG still OK) — these are **drift-caused** mutations
- M ∩ Ω^c ≠ ∅ always (CG failure forces Mutation regardless of drift)

**Key result from CPTT-VTS:** Ω^c → M is unconditional. Coherence is an
independent boundary — not derivable from drift alone.

|-------|-----------|----------------------|

## 1.2.ah.6 Trajectory Rules

### Allowed single-step transitions

```
Stable     → Stable        (normal evolution)
Stable     → Transition    (approaching boundary)
Transition → Stable        (retreating from boundary)
Transition → Transition    (hovering at boundary)
Transition → Mutation      (crossing boundary)
Stable     → Mutation      (only if drift > ε_L + m OR ¬CG_OK)
Mutation   → Mutation      (absorbing within session)
```

### Absorbing state policy

Within a single session, Mutation is an **absorbing state**: once entered, the
system cannot return to Stable or Transition without governance intervention
that constitutes a new session context.

Recovery (Mutation → Transition → Stable) requires:
- drift returns below ε_L − m
- CG_OK restored
- sustained for ≥ k consecutive steps (k configurable, default k=1)
- governance explicitly permits recovery (RECOVER action)

If recovery is not declared in session config, Mutation is strictly absorbing.
