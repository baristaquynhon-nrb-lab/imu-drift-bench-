## 6.y.4.1 Purpose

Introduce the formal architectural boundary separating:
- **Representation Phase (RP)** operators
- **Epistemic Phase (EP)** operators

Define the necessary and sufficient condition for an operator to remain
in the RP gauge group, and formalize the firewall preventing silent
epistemic drift.

---

## 6.y.4.2 Setting

### Spaces

```
ℋ   — representation fiber space (dim n_H)
ΔP  — epistemic base manifold (dim n_P, where n_P ≤ n_H)
```

### Maps

```
Encode : ΔP → ℋ       (embedding of epistemic projection into fiber)
Decode : ℋ  → ΔP       (projection from fiber onto epistemic base)
```

Canonical realization:
```
Encode(ΔP) = [ΔP ; 0]          (pad with zeros in fiber-only axes)
Decode(h)  = h[0 : n_P]        (project onto first n_P components)
```

Projection consistency:
```
Decode ∘ Encode = Id|_{ΔP}
```

---

## 6.y.4.3 Boundary Criterion

### Definition (RP Membership)

An operator T : ℋ → ℋ belongs to the **Representation Phase** iff:

```
T ∈ RP  ⇔  Decode ∘ T ∘ Encode = Id|_{ΔP_valid}
```

Equivalently, T preserves the epistemic projection for all valid
epistemic inputs.

### Definition (EP Membership)

```
T ∈ EP  ⇔  ∃ ΔP_valid such that Decode(T(Encode(ΔP_valid))) ≠ ΔP_valid
```

Any operator that alters at least one epistemic projection is classified
as Epistemic Phase.

---

## 6.y.4.4 Matrix Characterization

When T is a linear operator (matrix) on ℋ = ℝ^{n_H}:

### Round-Trip Criterion (Boundary Law)

```
T ∈ RP  ⇔  T[0:n_P, 0:n_P] = I_{n_P}
```

The top-left n_P × n_P block of T must be the identity matrix.
Since Encode pads zeros in fiber axes, the top-right block T[0:n_P, n_P:]
does not affect the round-trip on Encode(ΔP).

### Full Gauge Group (Projection Preservation on all h ∈ ℋ)

For the stronger property Decode(T(h)) = Decode(h) for ALL h:

```
T = [ I_{n_P}   0      ]     ← full gauge group G_RP^strong
    [ A         B      ]
```

This requires both T[0:n_P, 0:n_P] = I_{n_P} AND T[0:n_P, n_P:] = 0.

### EP Classification

```
T ∈ EP  ⇔  T[0:n_P, 0:n_P] ≠ I_{n_P}
```

Any deviation in the base-to-base block means the operator alters
epistemic content.

## 6.y.4.5 RP Gauge Group

### Definition

```
G_RP = { T ∈ GL(ℋ) : Decode ∘ T ∘ Encode = Id|_{ΔP} }
```

### Closure Properties

1. **Identity:** Id ∈ G_RP (trivially preserves projection)
2. **Composition:** T₁, T₂ ∈ G_RP ⟹ T₁ · T₂ ∈ G_RP
3. **Inverse:** T ∈ G_RP ⟹ T⁻¹ ∈ G_RP (when invertible)

Proof of composition:
```
Decode(T₁(T₂(Encode(ΔP))))
= Decode(T₁(Encode(ΔP)))     [since T₂ preserves projection]
= ΔP                          [since T₁ preserves projection]
```

(Note: intermediate step uses that T₂(Encode(ΔP)) has the same base
projection as Encode(ΔP), so T₁ sees a valid fiber input.)

## 6.y.4.6 Architectural Firewall

```
ℋ (representation fiber space)
    │  gauge transforms only (G_RP)
    ▼
ΔP (epistemic base manifold)
    │  CG + LawVault governance required for EP operators
    ▼
```

### Rules

1. **No silent epistemic drift:** Any operator altering ΔP is
   automatically classified as EP → must pass CG + LawVault.

2. **RP operators are free:** Operators in G_RP may transform ℋ
   without governance overhead, since they cannot alter epistemic content.

3. **Boundary check is decidable:** For linear operators, checking
   T[0:n_P, 0:n_P] = I_{n_P} is O(n_P²), always terminating.
